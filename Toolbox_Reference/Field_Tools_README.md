\# Field Tools



Custom ArcPy Python toolbox used for field management and geometry-based metric calculations.



\## Toolbox Alias



`field\_tools`



\## Included Tools



\### Add Standard Metric Field



Adds and calculates a standard geometry-based metric field such as area or length.



Used in the workflow for:

\- adding stream length fields

\- adding subbasin area fields

\- standardizing metric field names and aliases
